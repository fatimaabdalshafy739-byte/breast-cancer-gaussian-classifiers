# Gaussian Classifiers for Breast Cancer Diagnosis

## Project Description
In this project, I used Gaussian models to classify breast cancer samples into two classes: **Malignant (cancerous)** and **Benign (non-cancerous)**.

I worked with the Breast Cancer Wisconsin dataset and applied different classification methods to understand how they work and compare their results.

## What I Did
- Calculated the mean, standard deviation, and prior probabilities for one feature.
- Compared Equal Spread and Own Spread decision rules.
- Calculated covariance matrices using two features.
- Applied LDA, QDA, and Gaussian Naive Bayes classifiers.
- Studied the effect of correlated features on QDA.
- Reduced the number of features to solve the singular covariance problem.
